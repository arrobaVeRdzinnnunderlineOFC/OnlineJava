# Online Java

IDE de Java virtual e *zero-install* em JavaScript puro, pensado para escrever, organizar ficheiros virtuais, usar `import` entre classes do projeto, executar no browser sem instalar nada e exportar `.jar` ou executável.

## Funcionalidades
- **Sistema de ficheiros virtual (VFS):** Cria e remove ficheiros `.java` e pacotes virtuais sem mexer nos ficheiros do computador.
- **Zero-install:** Abre `index.html` diretamente no browser (ou corre via Electron).
- **Suporte a `package` e `import`:** Liga classes entre ficheiros virtuais e suporta utilitários como `ArrayList`.
- **Exportação:** Gera `.jar` (ZIP com `META-INF/MANIFEST.MF`) e launcher executável.
